# V5.5 — Flujo PIN → equipo → alineación → pizarra

- El partido real obtenido mediante PIN abre una etapa de confirmación del equipo autorizado.
- El equipo propio se determina mediante el usuario autenticado y los mánagers asignados al partido; el PIN no concede permisos por sí solo.
- El siguiente paso permite editar la alineación del equipo propio.
- Tras guardar la alineación propia, se habilita el acceso a la pizarra y los controles de anotación.
- Se preservan las funciones de anotación, consulta, sustitución y sincronización existentes en V5.4.

**Limitaciones:** primera corrección funcional del flujo, no es aún el rediseño deportivo final de la pizarra. No se ha compilado con Flutter en este entorno; compilar y validar con GitHub Actions. Este ZIP no ejecuta SQL.

Subir el contenido del ZIP a la raíz del repositorio, sin añadir una carpeta contenedora.
